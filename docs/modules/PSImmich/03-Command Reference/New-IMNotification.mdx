## SYNOPSIS

Sends a notification to a specific Immich user

## SYNTAX

```powershell
New-IMNotification [[-Session] <ImmichSession>] [-UserId] <String> [-Title] <String> [[-Description] <String>]
 [[-Level] <String>] [[-Type] <String>] [[-Data] <Hashtable>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Creates a notification in the notification inbox of a user on the Immich server.
This is an administrator
operation.
Only the parameters you specify are sent, so Immich applies its own defaults for the rest.

## EXAMPLES

### EXAMPLE 1

```powershell
New-IMNotification -UserId 'bde7ceba-f301-4e9e-87a2-163937a2a3db' -Title 'Maintenance tonight'
```

Sends a notification with the specified title to the user.

### EXAMPLE 2

```powershell
New-IMNotification -UserId 'bde7ceba-f301-4e9e-87a2-163937a2a3db' -Title 'Backup failed' -Level error -Type BackupFailed -Description 'Check the server log.'
```

Sends an error notification describing a failed backup.
