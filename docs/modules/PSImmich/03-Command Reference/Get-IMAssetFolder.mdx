## SYNOPSIS

Browses the folders that Immich assets were imported from

## SYNTAX

### list (Default)

```powershell
Get-IMAssetFolder [-Session <ImmichSession>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### path

```powershell
Get-IMAssetFolder [-Session <ImmichSession>] -Path <String> [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Without parameters, returns the unique folder paths that the assets on the server were
originally stored in.
With -Path, returns the assets whose original file is directly
inside the specified folder.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-IMAssetFolder
```

Returns the unique folder paths of all assets on the server.

### EXAMPLE 2

```powershell
Get-IMAssetFolder -Path '/usr/src/app/upload/library/2024'
```

Returns the assets whose original file is in the specified folder.
