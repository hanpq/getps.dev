## SYNOPSIS

Retrieves Immich plugin methods

## SYNTAX

```powershell
Get-IMPluginMethod [[-Session] <ImmichSession>] [[-Id] <String>] [[-Name] <String>] [[-Title] <String>]
 [[-Description] <String>] [[-PluginName] <String>] [[-PluginVersion] <String>] [[-Trigger] <String>]
 [[-Type] <String>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Retrieves the plugin methods available on the Immich server.
Methods are the actions that installed plugins expose for use in workflows.
The list can be filtered by name, plugin, trigger and workflow type.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-IMPluginMethod
```

Retrieves all plugin methods available to the current user.

### EXAMPLE 2

```powershell
Get-IMPluginMethod -Trigger 'AssetCreate'
```

Retrieves the plugin methods that can be used in workflows triggered by asset creation.

### EXAMPLE 3

```powershell
Get-IMPluginMethod -PluginName 'my-plugin' -Type 'AssetV1'
```

Retrieves the AssetV1 methods provided by the plugin named 'my-plugin'.
