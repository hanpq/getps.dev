## SYNOPSIS

Downloads Immich storage integrity reports to local storage

## SYNTAX

### file (Default)

```powershell
Save-IMIntegrityReport [-Session <ImmichSession>] -Id <String> -Path <FileInfo>
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### csv

```powershell
Save-IMIntegrityReport [-Session <ImmichSession>] -Type <String> -Path <FileInfo>
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Downloads either the file for a single integrity report item, or the CSV export of all items of one report type.
The Path parameter is the full destination file path, because the server does not provide a usable file name for these downloads.

## EXAMPLES

### EXAMPLE 1

```powershell
Save-IMIntegrityReport -Type 'checksum_mismatch' -Path 'C:\Reports\checksum-mismatch.csv'
```

Exports all checksum mismatch report items to a CSV file.

### EXAMPLE 2

```powershell
Get-IMIntegrityReport -Type 'missing_file' | Select-Object -ExpandProperty items | Save-IMIntegrityReport -Path 'C:\Reports\missing.txt'
```

Downloads the file of the first missing file report item.
Save each item to a unique path when you need more than one file.
