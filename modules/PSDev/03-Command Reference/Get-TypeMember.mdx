## SYNOPSIS

Gets members of a .NET type or object.

## SYNTAX

### typename (Default)

```powershell
Get-TypeMember [-TypeName] <Type> [-StaticOnly] [-EnumOnly] [-MemberType <String>] [-MemberName <String>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### inputobject

```powershell
Get-TypeMember -InputObject <Object> [-StaticOnly] [-EnumOnly] [-MemberType <String>] [-MemberName <String>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Returns information about members such as properties, methods, events,
and fields.
Specify a type or pipe an object to inspect its type.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-TypeMember -TypeName ([string]) -MemberType Property
```

Lists the properties of the String type.

### EXAMPLE 2

```powershell
'text' | Get-TypeMember -MemberName Length
```

Gets the Length member from the type of the input string.
