## SYNOPSIS

## SYNTAX

```powershell
Use-CombSort [-InputObject] <Object> [-ReturnDiagnostics] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

This function sorts objects using the comb sort algorithm.
It improves on bubble sort by
comparing items separated by a gap that shrinks by a factor of 1.3 for every pass, which
removes small values (turtles) near the end of the array early.

## EXAMPLES

### EXAMPLE 1

```powershell
3,2,1 | Use-CombSort
```

Sorts the array using comb sort
