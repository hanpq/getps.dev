## SYNTAX

```powershell
 [<CommonParameters>]
```

## DESCRIPTION

This function sorts objects using the stooge sort algorithm.
It is a recursive sorting algorithm
with a notably bad time complexity of O(n^2.71).
If the first item is larger than the last they
are swapped, and if the range contains three or more items the first two thirds, the last two
thirds and then the first two thirds again are sorted recursively.

## EXAMPLES

### EXAMPLE 1

```powershell
3,2,1 | Use-StoogeSort
```

Sorts the array using stooge sort
