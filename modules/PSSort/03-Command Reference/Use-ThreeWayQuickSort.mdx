## SYNOPSIS

## SYNTAX

```powershell
Use-ThreeWayQuickSort [-InputObject] <Object> [-ReturnDiagnostics] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

This function sorts objects using the 3-way quick sort algorithm, also known as the Dutch
national flag partitioning.
The array is partitioned into three parts, items less than the
pivot, items equal to the pivot and items greater than the pivot.
This makes the algorithm
efficient on arrays containing many duplicate values.

## EXAMPLES

### EXAMPLE 1

```powershell
3,2,1 | Use-ThreeWayQuickSort
```

Sorts the array using 3-way quick sort
