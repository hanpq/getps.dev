## SYNOPSIS

## SYNTAX

```powershell
Use-InsertionSort [-InputObject] <Object> [-ReturnDiagnostics] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

This function sorts objects using the insertion sort algorithm.
Each item is picked from the
unsorted part of the array and inserted at its correct position in the sorted part.

## EXAMPLES

### EXAMPLE 1

```powershell
3,2,1 | Use-InsertionSort
```

Sorts the array using insertion sort
