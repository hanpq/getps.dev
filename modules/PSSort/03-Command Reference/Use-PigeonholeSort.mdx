```powershell
 [<CommonParameters>]
```

## DESCRIPTION

This function sorts integers using the pigeonhole sort algorithm.
One pigeonhole is created for
every value in the range between the smallest and the largest item, every item is placed in its
hole and the holes are then emptied in order.
Since this is a non comparison based algorithm no
comparisons are made and that counter will remain zero.
The swap counter is used to count item
writes instead.

## EXAMPLES

### EXAMPLE 1

```powershell
3,2,1 | Use-PigeonholeSort
```

Sorts the array using pigeonhole sort
