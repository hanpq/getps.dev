## SYNOPSIS

Retrieves Immich storage integrity reports

## SYNTAX

### report (Default)

```powershell
Get-IMIntegrityReport [-Session <ImmichSession>] -Type <String> [-Cursor <String>] [-Limit <Int32>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### summary

```powershell
Get-IMIntegrityReport [-Session <ImmichSession>] [-Summary] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Retrieves the storage integrity report items for one report type, or the summary counts for all report types.
Report types are untracked_file, missing_file and checksum_mismatch.
The report output includes the next cursor when more items are available; pass it to -Cursor to retrieve the next page.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-IMIntegrityReport -Summary
```

Retrieves the number of untracked, missing and checksum mismatch items.

### EXAMPLE 2

```powershell
Get-IMIntegrityReport -Type 'missing_file' -Limit 50
```

Retrieves the first page of missing file report items.

### EXAMPLE 3

```powershell
Get-IMIntegrityReport -Type 'untracked_file' | Select-Object -ExpandProperty items
```

Retrieves the untracked file report items.
