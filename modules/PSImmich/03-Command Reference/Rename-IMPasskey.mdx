## SYNOPSIS

Updates the name of a passkey.

## SYNTAX

### name (Default)

```powershell
Rename-IMPasskey [-Session <ImmichSession>] -Id <String> -Name <String> [-ProgressAction <ActionPreference>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

### clear

```powershell
Rename-IMPasskey [-Session <ImmichSession>] -Id <String> [-ClearName] [-ProgressAction <ActionPreference>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Renames a passkey or clears its name.
Requires the passkey.update permission.
Responses are returned as received so nullable fields are preserved.

## EXAMPLES

### EXAMPLE 1

```powershell
Rename-IMPasskey -Id 'bde7ceba-f301-4e9e-87a2-163937a2a3db' -Name 'Security key'
```

Renames the specified passkey.

### EXAMPLE 2

```powershell
Get-IMPasskey -Id 'bde7ceba-f301-4e9e-87a2-163937a2a3db' | Rename-IMPasskey -ClearName
```

Clears the passkey's name.
