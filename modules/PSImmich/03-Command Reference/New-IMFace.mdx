## SYNOPSIS

Creates a new face detection for an asset

## SYNTAX

```powershell
New-IMFace [[-Session] <ImmichSession>] [-AssetId] <String> [-PersonId] <String> [-X] <Int32> [-Y] <Int32>
 [-Width] <Int32> [-Height] <Int32> [-ImageWidth] <Int32> [-ImageHeight] <Int32>
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Creates a new face that has not been discovered by facial recognition.
The content of the bounding box is considered a face.
This is useful for manually marking faces that the automatic face detection might have missed.

## EXAMPLES

### EXAMPLE 1

```powershell
New-IMFace -AssetId 'asset-uuid' -PersonId 'person-uuid' -X 100 -Y 150 -Width 200 -Height 250 -ImageWidth 1920 -ImageHeight 1080
```

Creates a new face detection at the specified coordinates for the given asset and person.

### EXAMPLE 2

```powershell
$FaceData = @{
    AssetId = 'asset-uuid'
    PersonId = 'person-uuid'
    X = 100
    Y = 150
    Width = 200
    Height = 250
    ImageWidth = 1920
    ImageHeight = 1080
}
New-IMFace @FaceData
```

Creates a face detection using parameter splatting.
