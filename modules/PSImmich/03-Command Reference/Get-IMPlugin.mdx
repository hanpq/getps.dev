## SYNOPSIS

Retrieves Immich plugins

## SYNTAX

### list (Default)

```powershell
Get-IMPlugin [-Session <ImmichSession>] [-Name <String>] [-Title <String>] [-Version <String>]
 [-Description <String>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### id

```powershell
Get-IMPlugin [-Session <ImmichSession>] -Id <String> [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Retrieves one or more plugins from the Immich server.
Can retrieve all plugins, optionally filtered, or a specific plugin by ID.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-IMPlugin
```

Retrieves all plugins available to the current user.

### EXAMPLE 2

```powershell
Get-IMPlugin -Id 'bde7ceba-f301-4e9e-87a2-163937a2a3db'
```

Retrieves a specific plugin by its ID.

### EXAMPLE 3

```powershell
'plugin1-uuid', 'plugin2-uuid' | Get-IMPlugin
```

Retrieves multiple plugins by piping their IDs.
