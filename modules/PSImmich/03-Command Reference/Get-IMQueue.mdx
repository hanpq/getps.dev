## SYNOPSIS

Retrieves Immich queue information

## SYNTAX

### list (Default)

```powershell
Get-IMQueue [-Session <ImmichSession>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### name

```powershell
Get-IMQueue [-Session <ImmichSession>] -Name <String[]> [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Retrieves information about one or more queues from Immich.
Queues handle background processing
tasks like thumbnail generation, metadata extraction, face detection, and more.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-IMQueue
```

Retrieves information for all queues.

### EXAMPLE 2

```powershell
Get-IMQueue -Name thumbnailGeneration
```

Retrieves information for the thumbnail generation queue.

### EXAMPLE 3

```powershell
Get-IMQueue -Name faceDetection, facialRecognition
```

Retrieves information for multiple specific queues.
