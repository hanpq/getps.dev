## SYNOPSIS

Lists which users have access to people

## SYNTAX

```powershell
Get-IMPersonAccess [[-Session] <ImmichSession>] [[-Direction] <String>] [[-PersonId] <String>]
 [[-Role] <String>] [[-SharedById] <String>] [[-SharedWithId] <String>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Returns the sharing relationships for people.
Each entry describes a person, the user
that shared it, the user it was shared with, and the access role that was granted.
All filters are optional and are combined.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-IMPersonAccess
```

Returns all people access relationships visible to the current user.

### EXAMPLE 2

```powershell
Get-IMPersonAccess -Direction shared-by -Role admin
```

Returns the admin grants the current user has given to other users.
