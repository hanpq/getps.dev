## SYNOPSIS

Shares people with other users

## SYNTAX

### Person (Default)

```powershell
Add-IMPersonAccess [-Session <ImmichSession>] -PersonId <String[]> -SharedWithId <String[]> -Role <String>
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### Everyone

```powershell
Add-IMPersonAccess [-Session <ImmichSession>] [-Everyone] -SharedWithId <String[]> -Role <String>
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Gives the specified users access to people with the specified role.
Existing access
for the same users is updated to the new role.
Use -PersonId to share specific people,
or -Everyone to share all people owned by the current user.

## EXAMPLES

### EXAMPLE 1

```powershell
Add-IMPersonAccess -PersonId 'bf973405-3f2a-48d2-a687-2ed4167164be' -SharedWithId '9c4e0006-3a2b-4967-94b6-7e8bb8490a12' -Role read
```

Gives the user read access to the specified person.

### EXAMPLE 2

```powershell
Add-IMPersonAccess -Everyone -SharedWithId '9c4e0006-3a2b-4967-94b6-7e8bb8490a12' -Role write
```

Gives the user write access to all people owned by the current user.
