## SYNOPSIS

Creates a new Immich workflow

## SYNTAX

```powershell
New-IMWorkflow [[-Session] <ImmichSession>] [-Name] <String> [[-Description] <String>] [-Trigger] <String>
 [[-Enabled] <Boolean>] [[-Logging] <Boolean>] [[-Steps] <Hashtable[]>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Creates a new workflow in Immich with the specified name and configuration.
Workflows can be created with
empty filters and actions and configured later.
Note: Workflow functionality is in Alpha state as of Immich v2.3.1.

## EXAMPLES

### EXAMPLE 1

```powershell
New-IMWorkflow -Name 'Auto Tag Photos' -Trigger 'AssetCreate' -Description 'Automatically tag uploaded photos'
```

Creates a new workflow with basic information.

### EXAMPLE 2

```powershell
New-IMWorkflow -Name 'Process Videos' -Trigger 'AssetTagged' -Enabled:$false
```

Creates a new workflow that is initially disabled.
